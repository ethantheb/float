Float

Shortcut

Open palette: Not set

In Helium you can bind this to Ctrl+T.

Behavior

Opened in a new tab when the palette can't appear on the current page (browser pages, the Web Store, some Google sites).

The browser puts focus in the address bar on new tab pages. When on, the new tab page is swapped for an identical tab so you can type straight away. The address bar then shows the extension's URL.

Use %s for the query, e.g. https://kagi.com/search?q=%s.

Appearance

Any CSS color. Leave empty for the theme default.
